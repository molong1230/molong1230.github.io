課程專案

課程總覽與學習紀錄： 11402_CS351。 下列為各專案儲存庫，內含原始碼、測試與文件。

Project 0：Two Sum

目標：在整數陣列中找出兩個索引，使其和等於目標值。

演算法：實作 twoSumArray（暴力 O(n²)）與 twoSumHashTable（雜湊表平均 O(n)），並以 benchmark 比較效能。

亮點：C++20 + CMake、單元測試（ctest）、GitHub Actions CI、Docker 建置驗證。

Project B：CSV Mini Database

目標：以 CSV 為資料表，建置輕量查詢引擎，模擬從解析到執行的資料庫流程。

功能：載入 CSV、解析 SQL-like 查詢（SELECT / WHERE / ORDER BY / LIMIT、聚合），透過 csvdb_cli 輸出結果。

亮點：完整軟體文件（SRS、SDS、測試計畫等）、模組化 C++ 架構、CI 自動測試。

AI 輔助開發反思

  • 如何使用：在 Cursor 等工具中，以自然語言描述需求、請 AI 協助產生初稿與重構建議。
  • AI 的幫助：加快 HTML/CSS 排版、README 撰寫、測試案例草稿與除錯方向整理。
  • 需要自行驗證：演算法正確性、測試是否通過、連結與學號是否正確、是否符合作業規格。
  • 學到的事：AI 適合當「加速器」，但版本控制、理解程式邏輯與口頭展示仍須自己掌握。
